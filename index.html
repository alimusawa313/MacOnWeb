Bitbucket & GitHub

Watch a branch or open PRs. Poll on a timer, or take webhooks (with HMAC secrets) for instant push-based builds — and post the status back as a commit check.

macon.yml pipelines

Bitrise-style workflows: before_run/after_run chains, triggers, env, run_if conditions and always-run steps — defined in your repo.

Test matrix

macon.yml

Pipelines that live in your repo.

Composable workflows, a test matrix, and trigger routing — the same file runs in the app or the CLI.

name: PlanPal iOS CI workflows: _setup: steps: - { name: Gems, script: bundle install } - { name: SwiftLint, script: swiftlint lint --strict } test: before_run: [_setup] steps: - name: Unit Tests script: bundle exec fastlane test - name: Danger run_if: '[ -n "$MACON_PR_ID" ]' # only on PRs script: bundle exec danger beta: before_run: [test] after_run: [_notify] steps: - { name: TestFlight, script: bundle exec fastlane beta } _notify: steps: - { name: Slack, always_run: true, script: ./scripts/notify.sh }
test: steps: - name: UI Tests # fan out across devices × OS — 4 runs, one push matrix: device: ["iPhone 17 Pro", "iPad Air 11-inch (M4)"] os: ["26.4", "26.5"] script: bundle exec fastlane test \ device:"$MACON_MATRIX_DEVICE" os:"$MACON_MATRIX_OS" # every step also gets MACON_COMMIT, MACON_BRANCH, MACON_REPO, # MACON_WORKFLOW, MACON_BUILD_NUMBER, MACON_PR_* on PR builds — # plus provider-native BITBUCKET_* / GITHUB_* so tools like Danger work.
triggers: - { pull_request: "*", workflow: test } # any PR - { branch: main, workflow: beta } - { branch: "dev-*", workflow: test } # globs supported # no workflow flag? MacOn matches the branch/PR here — # the same routing in the app, the CLI, and the phone.

Homebrew

Install the CLI.

One tap, one install. Then bootstrap the toolchain and start watching.

zsh — macon

1 · Tap & install

# add the tap, then install brew tap alimusawa313/macon https://github.com/alimusawa313/homebrew-macon brew install macon

2 · Check the machine

macon init # installs missing tools macon sims list # iOS / watchOS / tvOS / visionOS

3 · Watch & build

# poll a branch and build every commit macon watch --workspace acme --repo app --branch main # or GitHub, instant, via webhook macon watch --provider github --workspace org \ --repo app --webhook --port 8787

4 · Run it unattended & drive it remotely

# export from the app, run headless as a service macon install-service --config macon-export.json --companion # then, from any terminal macon trigger "My App" --follow # build now, exit 0/1 by result

See & drive

The Mac's screen, in your hand.

Hardware-encoded H.264 out of the Mac, hardware-decoded on the phone — so 60 fps doesn't stutter, and 120 fps is real on ProMotion.

  • Resolution & frame rate, live: 360p → full, 30/60/120 fps, adaptive bitrate for weak links.
  • Touchscreen or virtual trackpad — tap-to-click or laptop-style relative moves, with adjustable size, opacity and sensitivity.
  • A Sidecar-style Touch Bar: sticky ⌘⌥⌃⇧ modifiers, spaces, Mission Control, media keys, volume.
  • CompactOS: tap a Mac app and it refits to your device — big readable text, direct touch, window switcher, keyboard-aware.

CompactOS — Mac apps, phone-sized

Streams just one window, resized to your screen and orientation. Your Mac's apps behave like phone apps — Xcode included.

Capture that respects you

Runs only while someone is watching, gated by an explicit toggle on the Mac, and macOS Screen Recording permission.

Automate

A deck of keys and a canvas of flows.

Turn the device into a Stream Deck — then go further and wire up whole automations as clay blocks on physically swinging strings.

  • Deck keys launch Mac apps (with their real icons), fire ⌘⌥⌃⇧ shortcuts, or run sequences — open Chrome → wait → type → return.
  • Flows chain shell, HTTP, JSON, files, PDF, clipboard, screenshots and AI blocks; the Mac executes, you watch per-block results live.
  • Describe it instead: type or dictate “every morning, fetch HN, summarize, speak it” and the AI composer wires the blocks for you.

Shortcuts deck

Fully customizable keys — labels, emoji, colors — with drag-rearrange and a fill-screen grid. Liquid-glass pretty, one-tap fast.

Flows with real physics

The canvas ropes sag and swing (verlet simulation). Off by default on the Mac — flows run shell commands, so you opt in explicitly.

Code

A pocket dev environment.

The workspace is a mini IDE pointed at your Mac: browse the repo, edit with tabs, run real terminals, build with Xcode.

  • File explorer + tabbed editor — type locally with zero latency, save syncs back to the Mac.
  • Real zsh terminals, multiple tabs, ANSI colors, a key row for Ctrl-C/Tab/arrows — scrollback survives closing the panel.
  • Xcode in the loop: pick a scheme, build, test, clean — right from the device.
  • Code assistant with the open file as context and @-mentions for more — Claude with your key, or local Ollama models.

Tabbed terminals

Independent PTYs at the workspace root. Tail a build, poke a simulator, commit a fix — like VS Code's panel, on a phone.

Fix the pipeline from bed

Build broke on a YAML typo? Open macon.yml in the workspace, fix it, save, re-run — without standing up.

Talk to it

An AI copilot for the whole Mac.

Chat with models running on your own hardware, or hand the Mac a task out loud and watch it work.

  • Local AI chat via Ollama on the Mac — private, on-device, with image and PDF attachments.
  • Voice chat that speaks back (a Piper voice on the Mac, if installed) — hands-free mode keeps the conversation going.
  • Dictate-to-drive agent: it reads the screen and accessibility tree, plans steps, and drives the Mac — pausing for your approval in supervised mode.
  • Web too: with Playwright installed, the agent automates a real browser alongside Mac apps.

Voice agent, supervised

Watch the live screen while the agent works underneath, approving each step — or let it run and barge in by talking over it.

Bring your own AI

Claude, OpenAI, Gemini, a local Ollama model, or any OpenAI-compatible endpoint. Keys live in the Mac's Keychain — never on the phone. All of it optional.

Power & presence

Wake it, unlock it, never lose it.

The companion keeps the Mac reachable and brings it back to life from anywhere — every power an explicit, opt-in toggle.

  • Stay awake & wake: a power assertion keeps it reachable; a Wake-on-LAN magic packet raises it from sleep.
  • Unlock from the phone: a themed 3D padlock page that animates open — typing a password stored only in the Mac's Keychain.
  • Privacy curtain: a customizable “please don't touch” wall over the physical screen while you drive remotely — burn-in aware, hotkey-dismissed.
  • Always connected: optional iCloud beacon re-points the phone when a tunnel URL rotates. Pair once, never re-type an address.

Wake & unlock

Works on the LAN or through a free Cloudflare tunnel — and over iCloud even when both are down. Honest about limits: FileVault preboot stays locked.

Fleet map

Your Mac at the center, every paired device hanging on a swinging string — live glow for the active ones, drag them around for fun.

Trust model

Off by default. Yours by design.

MacOn is built for one team on machines they own — and treats every remote power as a privilege you grant, not a default.

Pair once, explicitly

Single-use codes with a 15-minute TTL, rate-limited, verified in constant time. Every device gets its own revocable token.

Every power is a toggle

Screen viewing, control, CompactOS, flows, wake, unlock — all off until you flip them on, per capability, on the Mac itself.

Secrets stay in the Keychain

Tokens, ASC keys, the unlock password — in the macOS Keychain, never in your repo or logs. Your code is only ever checked out on your machine.

A tunnel URL grants nothing

Remote access rides HTTPS/WSS through Cloudflare, but the address alone is useless — pairing codes and bearer tokens are always required.
